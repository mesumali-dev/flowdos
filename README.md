> **Flowdos** is a modern, high-performance workflow automation and productivity platform featuring an integrated conversational AI chatbot designed to help developers and teams orchestrate complex daily tasks seamlessly.

---

## 🌟 Key Features

- **Conversational Task Assistant:** Integrated AI chatbot capable of understanding natural language prompts to create, update, and prioritize workflow tasks.
- **Workflow State Management:** Real-time task boards and pipeline management with dynamic status transitions.
- **Edge Middleware Routing:** Sub-millisecond route guarding and authentication handling using Next.js Edge Middleware.
- **Responsive Modern UI:** Clean, dark-mode-first interface built with Tailwind CSS, supporting desktop and mobile devices.
- **Type-Safe Architecture:** End-to-end type safety across components, utilities, and API payloads with TypeScript.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/mesumali-dev/flowdos.git

# Navigate into project directory
cd flowdos

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the platform.
